# TASK-035 — 경로 조회 후 출발·도착 정류장 목록 숨기기

| 항목 | 내용 |
|---|---|
| Phase | 5 — 사용성 개선 |
| 상태 | 구현(브랜치, 2026-10-27) — 사용자 확인 대기 |
| 관련 | FR-008~013 결과 화면, US-003 |
| 요청 | 사용자(2026-10-27, 휴대폰 실사용): "출발지 목적지 입력후 경로 조회하면 출발지 정류소 목록 도착지 정류소 목록은 안 보이게 하자. 휴대폰에서 스크롤해야 경로가 보여 불편" |

## 변경
- 경로 결과가 있는 동안 출발지·목적지 패널, 주변 정류장 목록(출발·목적지), 고른 정류장 카드, "승차 후보 N곳…" 문구를 숨김 → 패널에 경로 결과만
- 위쪽 출발·도착 요약을 누르면 해당 선택 화면과 목록이 다시 열림(결과는 유지). 출발지·목적지를 바꾸면 기존처럼 결과가 지워지고 다시 찾기
- 버그 예방: 현재 위치를 출발지로 두는 처리를 `OriginPanel`에서 `App`으로 옮김 — 패널을 숨겼다 다시 보일 때 출발지를 다시 설정해 결과가 지워지던 문제(확인 중 발견)

## 검증
- `npm test` 236개·`npm run build` 통과
- 휴대폰 크기 브라우저: 경로 찾기 후 목록 0개 → 출발 요약 누르면 출발지·목적지 패널과 목록 다시 표시, 결과 유지 확인
