- 상단 고정 앱 바, "어디로 갈까요?" 제목, 출발·도착 요약 카드(누르면 해당 입력으로 이동)
- 지도는 카드 안, 상태 문구·동의 철회는 지도 아래 작은 캡션
- 버튼: 파란 주 버튼 / 회색 보조 버튼(높이 52px, 모서리 14px), "경로 찾기"는 화면 하단 고정
- 목록 행: 이름(굵게)·정류장 번호(회색)·거리(오른쪽)·›, 선택 행은 연한 파랑
- 도착정보: 노선 + 오른쪽 큰 파란 "N분 후"
- 경로 결과 카드: 큰 소요시간(또는 "소요시간 미확인"), 직행/환승 표시, 노선 칩(→로 환승), 승하차·도보
- 상세: 설명 상자 + 세로 타임라인(버스 단계 보라 점·번호 = 지도 번호 마커)
- 장애 안내는 주황 안내 상자
- PoC 부제 "네이버 Dynamic Map 연결 테스트"·문서 제목 "지도 테스트" 제거(회귀 체크리스트 항목 아님)

## 2차: 지도 전체 화면 + 아래 패널(지도 동의 사용자)
- 지도가 화면 위쪽 전체를 차지하고, 출발·도착 요약 카드가 지도 위에 떠 있음(누르면 패널을 펼쳐 해당 입력으로 이동)
- 아래 패널(`src/ui/BottomSheet.tsx`): 손잡이를 누르거나 끌어 접기(화면 44%)·펼치기(전체 화면) 전환. 내용은 패널 안에서 스크롤
- **NAVER 로고 보호(Maps 약관, AGENTS 규칙 6):** 지도 영역은 접힌 패널 위에서 끝나므로 접힌 상태에서 패널이 지도·로고를 덮지 않음. 펼친 상태는 화면 전체를 덮어 지도를 보이지 않게 함(로고 없는 지도 일부를 노출하지 않음). 손잡이를 끄는 동안에만 일시적으로 지도 아래쪽이 덮일 수 있음
- 경로 상세를 열거나 "지도에서 지정"을 켜면 패널이 자동으로 접혀 지도가 보임
- 지도 범위 맞춤(`fitBounds`)은 위쪽 요약 카드를 피하도록 여백(위 150px)을 받음(`NaverMap`의 `fitPadding`, 기본값은 기존 40px)
- 지도 상태 문구·동의 철회는 패널 안 아래쪽 캡션(문구 변경 없음)
- 지도 미동의 사용자는 지도가 없으므로 1차의 카드 화면 그대로
