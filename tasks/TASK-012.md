## 목적
출발지 기준 반경 500m 정류장을 찾고, 0건이면 안내 후 사용자 동의 시에만 1km까지 재검색한다.

## 선행 조건
- [x] TASK-005 GATE-01 통과(조건부 — 조건은 D-24·D-26 가공 규칙으로 반영)
- [x] TASK-011 완료(브랜치)
- [x] D-03 승인(2026-10-26): 하버사인 직선거리, `거리 ≤ 반경` 포함, 반올림 없이 비교
- [x] D-20 승인(2026-10-26): 거리 오름차순, 동률 시 정류장 ID 순

## PRD 수용 기준 (원문)
- **AC-003:** 반경 500m 이내 정류장만 기본 결과에 포함한다. 0건일 때 1km 확대를 안내하며 사용자 동의 전에는 확대하지 않는다. 동의 후 1km까지 재검색하고 결과가 없으면 없다고 표시한다. 예시로 450m·500m 포함, 550m는 기본 결과에서 제외한다.

## 작업 항목
1. 순수 함수: 거리 계산, 반경 필터(좌표 없는 정류장 제외), 거리순 정렬(동률 시 정류장 ID 순 — D-20)
2. 상태 흐름: 500m 검색 → 결과 있음 / 0건 → 확대 안내(동의·취소) → 동의 시 1km → 결과 있음 / 없음 표시
3. 1km 초과 자동 확대 없음, 동의 없는 자동 확대 없음
4. 반경 상수는 설정값으로 분리(500, 1000)

## 테스트 케이스
- 450m·500m 정류장 포함, 550m 제외 (AC-003 예시)
- 0건 → 확대 안내 표시, 동의 전 1km 검색 호출 없음
- 동의 → 1km 이내만 포함, 1,001m 제외
- 동의 후 0건 → "정류장 없음" 표시, 추가 확대 없음
- 취소 → 확대하지 않음
- 좌표 없는 정류장은 결과에서 제외
- 경도·위도 뒤바뀐 정류장(D-24)은 반경 검색 결과에서 제외
- 거리 동률 정류장은 정류장 ID 순, 입력 순서를 섞어도 표시 순서 동일 (D-20)
