# TASK-033 — 정류장을 출발지로 골라도 걷는 거리는 현재 위치에서

| 항목 | 내용 |
|---|---|
| Phase | 5 — 사용성 개선 |
| 상태 | 구현(브랜치, 2026-10-27) — 사용자 확인 대기 |
| 관련 | FR-001·FR-002, FR-010·AC-010(도보 추정), D-06 (A), PRIV-001~003 |
| 요청 | 사용자(2026-10-27): "출발지를 노형초등학교 정류장으로 고르면 현재 내 위치에서 정류장까지의 직선 거리로 해줘", "일정 거리(예: 2km)를 넘을 때는 정류장 기준으로 계산하도록 변경" |

## 변경
- 출발지가 정류장이고 현재 위치를 이미 확인한 경우(위치 사용 허용), 출발 쪽 걷는 거리 = 현재 위치 → 각 승차 후보 정류장 직선거리(`toCandidates`). 정렬·"제때 탈 수 있는지" 판정·총 소요시간에 같은 값 사용
- 경로 상세의 출발 단계는 "현재 위치"로 표시
- 현재 위치를 모르면(위치 미허용) 이전처럼 고른 정류장 기준
- 승차 후보 정류장 집합(고른 정류장 주변 500m, AC-003·AC-007)은 그대로
- 좌표는 브라우저 메모리에서만 계산(서버·저장소 전송 없음, PRIV-001~003)

## 검증
- `npm test` 235개(걷는 거리 기준·2km 제한 테스트 추가)·`npm run build` 통과

- 현재 위치가 고른 정류장에서 **2km를 넘으면**(다른 곳에서 미리 찾는 경우) 정류장 기준으로 계산(사용자 지정 2026-10-27, `walkFromCurrentLocation`·`CURRENT_LOCATION_WALK_MAX_METERS`)
