# TASK-024 — 지도 정류장 마커에 정류장 이름 표시

| 항목 | 내용 |
|---|---|
| Phase | 5 — 사용성 개선 |
| 상태 | 구현(브랜치, 2026-10-27) — 사용자 확인 대기 |
| 관련 | FR-004·AC-004(지도·목록 동기화), FR-020·AC-020(경로 단계 마커), US-002·US-005 |
| 요청 | 사용자(2026-10-27, 아이패드 실사용 화면): "지도에 표시되는 정류소에 정류소명을 넣고 싶어" |

## 변경
- 주변 정류장 마커: 점 오른쪽에 정류장 이름(최대 2줄, 넘치면 …). 선택한 정류장은 빨간 굵은 글자(최대 3줄)
- 경로 단계 마커: 번호 오른쪽에 승차·환승·하차 정류장 이름(보라, 최대 3줄)
- 흰 테두리 글자로 지도 위에서도 읽히게 함. 라벨은 눌리지 않음(마커 점만 누름)
- 지도를 확대 수준 15 미만으로 축소하면 주변 정류장 이름을 숨김(겹침 방지). 선택한 정류장·단계 이름은 계속 표시
- **보안:** 정류장 이름은 외부 데이터(BIS)라 마커 HTML에 넣기 전에 이스케이프(`escapeHtml`)
- 이름은 스냅샷에 있는 값 그대로 — 줄이거나 만들지 않음(NFR-004)

## 검증
- `npm test` 216개(라벨 표시·이스케이프 테스트 2개 추가)·`npm run build` 통과
- 라벨 모양은 마커 HTML을 빌드된 CSS로 그려 캡처 확인
- 미확인: 실제 NAVER 지도 위 표시, 확대·축소 때 숨김 동작 — 작업 환경에서 SDK를 불러올 수 없어 미리보기·실기기 확인 필요. 아주 가까운 정류장(예: 길 건너 같은 이름 두 곳)은 이름이 겹칠 수 있음
