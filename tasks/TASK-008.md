# TASK-008 — 장소 검색 공급자 검증 (U-001, PRIV-004)

| 항목 | 내용 |
|---|---|
| Phase | 0 — 개발 착수 전 |
| 상태 | **1차 비교 완료(A안: Kakao·지도 지정·정류장명 검색), 사용자 선정 대기** — `docs/verification/U-001-place-search.md` |
| 관련 | U-001, PRIV-004, GATE-06, FR-002·006 |
| 결정 의존 | D-05 (결정 방식 승인 2026-10-26: 이 TASK의 비교표로 사용자 선정) |

## 목적
수동 출발지(FR-002)·목적지(FR-006) 선택에 쓸 장소 검색 수단 후보를 비교해 사용자가 선정할 수 있게 한다.

## 선행 조건
- [x] TASK-003 비용 검증 틀 확정(GATE-06 1차)
- [x] 비교 대상: A안 승인(2026-10-26) — 조사 가능한 후보만, 나머지는 미확인 표시

## 작업 항목
1. 후보별 비교(문서 조사): 무료 한도·초과 시 동작, 약관(상업 여부·캐시·출처 표시), 키 노출 필요성(브라우저 호출 가능 여부), 위치 편향 파라미터로 좌표가 전달되는지와 그 저장·재이용 조건
2. API 없이 가능한 대안: 지도에서 직접 위치 지정, 버스 데이터의 정류장명 검색 — 각 대안의 AC-002·AC-006 충족 여부
3. 사용자 선정 요청서 작성 — 공급자 후보와 임시 수단(지도 지정·정류장명 검색) 채택 여부를 함께 제안
4. 비교 기준에 "검색어만 전송 가능 여부(위치 편향 좌표 없이 제주 지역 결과 품질)"와 "REST 키를 서버에 둘 때 좌표 경유 여부(R-18)" 포함

## 수용 기준
- 후보별 비교표(비용·약관·PRIV-004·키 노출)가 출처와 함께 작성되어 있다.
- 사용자 선정 결과가 기록되기 전까지 어떤 공급자도 연동되지 않는다.
