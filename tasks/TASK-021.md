# TASK-021 — 지도 이용 고지·동의 (D-27)

| 항목 | 내용 |
|---|---|
| Phase | 2 — 위치·정류장 (다음 운영 배포 전 적용 권장 — R-22) |
| 상태 | 미착수 |
| 관련 | PRIV-004 §6.1, NAVER Maps 서비스 이용약관 제7조 ⑤·제5조 ②, FR-004·FR-020, NFR-006, R-22 |
| 결정 의존 | D-27(승인 2026-10-26, A안), D-12(문구 법적 충분성) |

## 목적
NAVER 지도 SDK를 불러오기 **전에** 이용자에게 지도 이용 시 정보 제공 사실을 알리고 동의를 받는다. 동의하지 않아도 지도 외 기능은 쓸 수 있게 한다.

## 선행 조건
- [x] D-27 승인(2026-10-26): 동의 후 SDK 로드, 미동의 시 지도 없이 이용, 동의 여부는 브라우저에만 기억
- [x] TASK-010 지도 모듈 분리(SDK 로더가 한곳에 있음)
- [ ] 고지 문구 초안 사용자 확인(D-12 — 법적 충분성은 사용자 판단)

## 범위
- 포함: 고지·동의 화면, 동의 전 SDK 미요청, 미동의 시 지도 영역 안내, 동의 철회 수단, 안내 내용 표시(앱 내), 테스트
- 제외: 서버 동의 기록(D-27 C안 미채택), 위치 권한 요청(TASK-011), 정식 이용약관·개인정보 처리방침 문서(D-12 결과에 따라 TASK-020)

## 작업 항목
1. 동의 상태: `unknown` / `granted` / `declined`. 브라우저 저장소(`localStorage`, 버전 키 예: `map-consent:v1`)에만 기억, 접근 실패 시 매번 묻기(서버 전송·저장 없음)
2. `granted`일 때만 `useNaverMaps`에 Client ID 전달 → SDK 스크립트 삽입. 그 전에는 지도 요청 0건
3. 고지 문구 초안(D-12에서 확정):
   > **지도 이용 안내**
   > 지도는 네이버 클라우드 플랫폼 지도 서비스(NAVER Maps)를 사용합니다.
   > 지도를 표시하는 동안 지도 영역과 서비스 이용 정보가 네이버클라우드㈜와 네이버㈜에 제공되어 보관·활용될 수 있습니다.
   > 동의하지 않아도 정류장 목록과 정류장 이름 검색은 이용할 수 있습니다.
   > [동의하고 지도 보기] [지도 없이 이용]
4. 미동의(`declined`) 시 지도 자리에 "지도를 사용하지 않음" 안내와 다시 동의할 수 있는 버튼
5. 동의 철회: 화면 안 "지도 이용 동의 철회" — 저장값 삭제 후 새로고침(이미 로드된 SDK는 페이지를 다시 열어야 제거됨)
6. PoC 회귀 체크리스트(TASK-001) 갱신: 지도 관련 항목은 "동의 후" 조건으로 변경(D-27로 승인된 동작 변경)

## 테스트 케이스
- 동의 전: SDK 요청 0건, 스크립트 태그 0개 (브라우저)
- 동의 후: SDK 요청 1회, 기존 PoC와 같은 지도 호출(스텁 SDK)
- 미동의: SDK 요청 0건, 안내 표시, 다시 동의 가능
- 저장값 `granted` 유지 시 새로고침 후 바로 로드, 저장소 접근 실패 시 고지 다시 표시
- 동의 철회 후 새로고침 → 고지 다시 표시, SDK 요청 0건
- 고지 화면 키보드 접근·스크린리더 레이블

## 수용 기준
- 어떤 경로로도 동의 전에 `oapi.map.naver.com` 요청이 발생하지 않는다.
- 동의 상태가 서버로 전송·저장되지 않는다.
- 미동의 상태에서도 화면이 깨지지 않고 지도 외 영역이 동작한다.
- `npm run build`, `npm test` 통과, PoC 회귀 체크리스트(갱신본) 통과.
