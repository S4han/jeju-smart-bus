## 목적
월 외부 서비스 과금 0원을 보장할 수 있는지 서비스별로 확인한다. 무료 한도 초과 시 자동 과금되는 구조이고 사전 차단 장치가 검증되지 않으면 운영에 적용하지 않는다(PRD §7 운영 정책).

## 선행 조건
- [x] 검토 대상 서비스 목록 ("TASK-003 진행" 승인, 기본 목록 사용: 제주 버스 API/공공데이터포털, NAVER Cloud Maps, Vercel, 장소 검색 후보, 도보 데이터 후보)

## 범위
- 포함: 공식 문서·약관·요금표·콘솔 설정 확인(사용자가 계정 화면 확인 필요 시 요청), 결과 기록
- 제외: 유료 플랜 가입, 결제수단 등록, 외부 API 실호출, Vercel 설정 변경

## 작업 항목 (서비스별)
1. 인증 방식, 무료 호출 한도(일/월), 한도 초과 시 동작(차단 / 자동 과금 / 서비스 정지)
2. 결제수단 등록 여부와 자동 과금 가능성, 사용량 상한·알림 설정 가능 여부
3. 이용 약관: 상업/비상업 조건, 데이터 재배포·캐시 허용 범위(D-10 연계), 출처 표시 의무
4. Vercel Hobby: 이용 조건, Functions·대역폭 한도, 초과 시 동작
5. NAVER 지도: Dynamic Map 무료 사용량, 초과 시 동작(D-15)

## 수용 기준
- 각 서비스에 대해 위 항목이 출처(문서 URL·확인일)와 함께 기록되어 있다.
- 서비스별 판정: **사용 가능(0원 보장)** / **조건부(차단 장치 필요)** / **사용 불가**.
- "조건부"는 차단 장치가 검증되기 전까지 운영 미적용으로 표시되어 있다.
- 기록에 계정 정보·키·결제 정보가 없다.
