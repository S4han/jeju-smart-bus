# TASK-007 — 소요시간 산정 가능성·산식 검증 GATE-05 (U-002)

| 항목 | 내용 |
|---|---|
| Phase | 0 — 개발 단계 필수 검증 |
| 상태 | 미착수 |
| 관련 | GATE-05, U-002, FR-010·014·015, R-02·11 |
| 결정 의존 | D-06 |

## 목적
총 소요시간 = 도보 + 대기 + 버스 이동 + 환승에 필요한 시간(PRD §3)의 각 구성요소를 **검증된 근거**로 산정할 수 있는지, 중복 없이 합산하는 산식을 제안한다.

## 선행 조건
- [ ] TASK-005(GATE-04), TASK-006(GATE-02·03) 결과
- [ ] 도보 데이터 후보 조사 범위 사용자 확인(D-06), 필요 시 TASK-002 PRIV-004·TASK-003 검증

## 작업 항목
1. 구성요소별 원천 후보: 도보(API/추정/없음), 대기(실시간 도착/시간표), 버스 이동(구간 시간표/운행 데이터), 환승(환승 도보 + 다음 버스 대기)
2. 중복 위험 식별: 예) 환승 시 "환승 도보시간"과 "다음 버스 대기시간"의 겹침, 실시간 도착 예정 시각에 이미 이동시간이 포함되는 경우
3. 산식 제안서: 각 항목의 출처 표시(실시간/추정/미확인), 하나라도 미검증이면 "총 소요시간 미확인" 처리(AC-010)
4. 샘플 경로 수작업 계산 예시

## 수용 기준
- 구성요소별 산정 가능 여부와 원천이 기록되어 있다.
- 중복 없는 산식이 예시와 함께 제안되어 있고 사용자 승인 항목으로 올라가 있다.
- GATE-05 판정: 통과 / 부분 통과(일부 경로만 시간 산정 가능) / 실패
