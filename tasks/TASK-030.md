## 변경
- **경로 탭:** 추천(시간 순, AC-011)·시간 미확인(AC-015) 순서 그대로 가로 탭. 처음엔 가장 빠른 경로를 자동 선택(예측이 늦게 와도 사용자가 고르기 전까지는 1순위를 따라감)
- **경로 상세:** 총 소요시간(크게) + "오전 9:48 – 오전 11:27 도착 예정"(지금 시각 + 계산된 총 시간, 추정 포함 표기) + 시간 막대(대기·버스·환승·도보, 계산된 분만. 시간이 없으면 정류장 수 비율·분 표시 없음)
- **세로 단계:** 출발 → 도보 → 승차(정류장명[방향]·번호·승차 예정 시각·노선 번호·방면·버스 도착 예정·"N개 정류장 이동 · N분"(펼치면 경유 정류장)) → (환승) → 하차 → 도보 → 도착. 추천 근거(AC-018)는 첫 줄 + 펼쳐 보기
- **하단 요약:** 고른 경로 총 시간·도착 예정 + "다시 찾기"
- 결과가 나오면 패널을 접힌 높이로 두어 지도(단계 번호·경유 정류장)와 요약을 함께 보여 줌. 지도에 선은 그리지 않음(D-16 유지, D-33 철회)
- **노선 번호(D-34):** routeNum이 노선 이름의 앞부분일 때만 큰 번호(254), 세부 이름(254-3)은 작게. 아니면 이름 그대로. 도착정보 목록에도 적용
- **정류소 방향:** BIS dirTp를 [북]·[남]·[동]·[서]로 이름 옆에 표시(주변 정류장·검색·도착정보·경로 상세). 값 없으면 표시 안 함
- 넣지 않음: 요금, "간선" 등 노선 종류, 배차 안내, 실제 도로 경로선, 길안내
