## 목적
외부 API 오류·호출 제한·무료 한도 소진 시 영향 범위를 안내하고, 추가 과금을 유발하는 호출을 하지 않으며, 검증되지 않은 대체 결과를 만들지 않는다.

## PRD 수용 기준 (원문)
- **AC-017:** 장애 시 영향을 받는 기능과 정보 부재를 안내한다. 무료 한도 소진 상태에서는 추가 과금 유발 호출을 실행하지 않고 해당 기능을 중단한다. 검증되지 않은 대체 결과를 생성하지 않는다.

## 작업 항목
1. 기능별 의존성 지도: 어떤 외부 서비스 장애가 어떤 기능(지도/정류장/도착/장소 검색/경로)에 영향을 주는지
2. 원인별 안내 문구: 장애 / 호출 제한 / 한도 소진 / 데이터 불일치 — 영향 기능과 사용 가능한 기능 명시
3. 한도 소진 감지(D-11): 상류 오류 코드(공공데이터포털 22 일일 초과·23 초당 초과, Kakao 429 — 실제 코드·형식은 TASK-005·008 실응답으로 확인)를 `quota_exhausted`/`rate_limited`로 정규화. 감지 시 해당 기능 호출 중단, 다른 기능은 유지
   - 재시도 억제: `quota_exhausted` 응답도 짧게 CDN 캐시해 같은 정류장 반복 호출을 막음(값은 GATE-04 후 결정). 함수 인스턴스 메모리 상태는 보조 수단으로만 사용(인스턴스 간 공유되지 않음 — R-09)
   - 외부 KV·DB로 호출 수를 세지 않음
4. 자동 과금 가능 서비스는 GATE-06에서 이미 배제됨을 재확인
5. 재시도 정책: 지수 백오프·상한, 무한 재시도 금지

## 테스트 케이스
- 도착정보 API 장애 → 도착정보만 "이용 불가", 정류장 검색은 유지
- 한도 소진 응답(오류 22·429 픽스처) → `quota_exhausted` 정규화, 이후 같은 요청은 캐시 응답으로 상류 호출 0회(목 검증), 사유 안내
- 초당 한도(오류 23) → `rate_limited`, 짧은 백오프 후 재시도 상한 준수
- 장애 중 캐시·추정으로 실시간처럼 표시하지 않음
- 지도 SDK 로드 실패 또는 NAVER Maps 이용 한도 도달로 차단(D-15) → "지도 이용 불가" 안내, 목록 기반 기능 유지(가능 범위 사용자 확인)
