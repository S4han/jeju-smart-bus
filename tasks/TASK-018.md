## 목적
경로별 도보 접근·승차·환승·하차 단계를 안내하고, 추천 이유를 규칙으로 설명하며, 확인된 지점만 지도에 표시한다.

## 선행 조건
- [x] TASK-013 완료(브랜치), TASK-017 **부분 완료** — 미완 부분(소요시간)은 AC-018에 따라 "값이 있는 항목만" 표시하므로 이 TASK를 막지 않음(2026-10-26 판단)
- [x] D-16 승인(2026-10-26): 마커 + 단계 번호만, 궤적 데이터 없으면 연결선 없음

## PRD 수용 기준 (원문)
- **AC-013:** 각 경로에서 구간별 정류장·노선·환승 순서를 확인할 수 있다. 확인되지 않은 정류장명이나 경유 정보를 생성하지 않는다.
- **AC-018:** 생성형 AI 호출 없이도 경로별 추천 근거를 표시한다. 근거 데이터가 없는 항목을 설명에 포함하지 않는다.
- **AC-020:** 유효 좌표가 있는 정류장과 경로 지점을 표시한다. 실제 도로·버스 운행 궤적 데이터가 없으면 추정 선을 실제 운행 경로처럼 표현하지 않는다.

## 작업 항목
1. 단계 목록: 도보(출발지→승차) → 승차(정류장·노선·방향) → 환승(정류장) → 하차 → 도보(하차→목적지). 데이터에 있는 명칭·ID만 사용
2. 규칙 설명 템플릿: 정렬 근거(총 소요시간·환승 횟수·도보시간) 중 **값이 있는 항목만** 문장에 포함. 추정 값은 "추정" 명시
3. 경로 비교 화면(US-004): 총 소요시간·환승 횟수·도보시간 나란히 표시
4. 지도: 승차·환승·하차 정류장 마커와 단계 번호(D-16). 궤적 데이터 없으면 정류장 간 연결선을 그리지 않음. 연결선이 필요해지면 새 사용자 승인
5. 생성형 AI 관련 코드·키·SDK 추가 금지

## 테스트 케이스
- 단계의 모든 정류장명·노선이 입력 데이터에 존재 (AC-013)
- 도보시간 없는 경로 → 설명에 도보시간 문장 없음 (AC-018)
- 네트워크 차단 상태에서도 설명 생성 (AC-018, AI 미사용)
- 좌표 없는 경로 지점 → 지도 미표시, 목록에는 표시 (AC-020)
- 궤적 데이터 없음 → 지도에 polyline 객체 0개, 마커에 단계 번호 표시 (AC-020, D-16)

## 보류 조건
궤적 데이터가 검증되기 전에는 연결선을 구현하지 않는다(D-16).
