# TASK-005 — 버스 API 실응답 검증: 정류장(GATE-01)·도착정보/시간표(GATE-04)

| 항목 | 내용 |
|---|---|
| Phase | 0 — 개발 단계 필수 검증 |
| 상태 | 미착수 |
| 관련 | GATE-01, GATE-04, U-006, FR-003·005·014, R-01·02 |
| 결정 의존 | D-09, D-10 |

## 목적
명세가 아닌 **실제 응답**으로 정류장 ID·명칭·좌표, 실시간 도착정보, 시간표 대체 데이터의 가용성을 확인한다.

## 선행 조건
- [ ] TASK-004 완료(키가 서버/로컬 비공개 환경에서만 사용됨)
- [ ] D-09: 제주 BIS API 정의 문서 확보(현재 저장소에 없음)
- [ ] 사용자의 **실호출 승인** 및 키 발급(키는 사용자가 비공개 환경에 설정)
- [ ] TASK-003에서 해당 API의 무료 한도 확인(검증 호출 수가 한도 내)

## 작업 항목
1. 정류장 목록·정류장 상세 조회: ID 형식, 명칭, 좌표 필드명·좌표계(WGS84 여부)·정밀도, 좌표 누락 정류장 비율, 전체 건수·응답 크기
2. 도착정보 조회: 정류장 ID 입력 → 응답 필드(노선, 도착 예정 시간/정류장 수, 갱신 시각), 빈 응답·오류 형식, 응답 시각 정보 존재 여부(D-04 근거)
3. 시간표·운행 데이터 존재 여부와 형식(FR-014 근거)
4. 오류·한도 초과 응답의 코드·형식(FR-017 근거)
5. 응답 샘플을 **키·불필요 정보 제거 후** 픽스처로 저장
6. 데이터 이용 조건(출처 표시, 재배포 가능 여부) 확인 → D-10 판단 근거

## 수용 기준
- GATE-01: 정류장 ID·명칭·좌표 실조회 성공 여부와 품질(누락률, 좌표계)이 기록되어 있다 → **통과/실패** 판정
- GATE-04: 실시간 도착정보 가용성, 시간표 대체 데이터 가용성 각각 판정
- 픽스처에 키·토큰·사용자 좌표가 없다.
- 실호출 횟수와 무료 한도 대비 사용량이 기록되어 있다.
