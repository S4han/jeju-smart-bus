## 작업 항목

실호출 계획(오퍼레이션·호출 수)은 `BIS-API-spec-summary.md` §5. 명세상 대상: Station/Station2(정류장), Bus(노선), StationRoutePr(경유 샘플), BusArrives(도착), BusInfo(첫·막차·배차 간격). 추가 확인: HTTPS 지원(R-20), `serviceKey` 필요 여부, 오류 코드 형식.

1. 정류장 목록·정류장 상세 조회: ID 형식, 명칭, 좌표 필드명·좌표계(WGS84 여부)·정밀도, 좌표 누락 정류장 비율, 전체 건수·응답 크기
2. 도착정보 조회: 정류장 ID 입력 → 응답 필드(노선, 도착 예정 시간/정류장 수, 갱신 시각), 빈 응답·오류 형식, 응답 시각 정보 존재 여부와 실제 갱신 주기(연속 조회로 관찰) → D-04 기준값 제안(결정 방식 승인 2026-10-26)
3. 시간표·운행 데이터 존재 여부와 형식(FR-014 근거)
4. 오류·한도 초과 응답의 코드·형식(FR-017 근거)
5. 응답 샘플을 **키·불필요 정보 제거 후** 픽스처로 저장
6. 데이터 이용 조건(출처 표시, 재배포 가능 여부) 확인 → D-10 적용(판단 기준 승인 2026-10-26)
   - 포털 "이용허락범위 제한 없음" + LINK 연계처 약관이 재배포·가공을 허용 → 정적 스냅샷 공개 배포 가능, 출처 표시 문구 기록
   - 연계처 약관이 금지하거나 확인 불가 → 공개 배포 불가로 판정, D-01 재검토 안 제출
