# TASK-015 — 목적지 검색·선택(FR-006)·승하차 후보 정류장(FR-007)

| 항목 | 내용 |
|---|---|
| Phase | 3 — 경로 |
| 상태 | 미착수 |
| 관련 | FR-006, FR-007, AC-006, AC-007, US-003, U-001, PRIV-004 |
| 결정 의존 | D-03, D-05 |

## 목적
사용자가 검색 결과에서 목적지를 선택하면 유효 좌표로 확정하고, 출발지·목적지 각각의 후보 정류장을 구한다.

## 선행 조건
- [x] 목적지 입력 수단 확정(D-05, 2026-10-26): 정류장명 검색 + 지도 직접 지정
- [ ] PRIV-004 §6.1(NAVER 지도) — 지도 직접 지정에 필요
- [ ] TASK-012 반경 검색 로직 완료

## PRD 수용 기준 (원문)
- **AC-006:** 사용자가 검색 결과에서 목적지를 선택하면 유효한 목적지 좌표로 경로 탐색을 시작한다. 장소 검색 실패·선택 전에는 임의 목적지로 탐색하지 않는다.
- **AC-007:** 각 위치에서 500m 후보를 구한다. 후보가 없는 위치에만 확대 동의를 요청하고 동의한 위치에 한해 1km 재검색한다. 후보가 끝내 없으면 경로를 만들어 내지 않는다.

## 작업 항목
1. 목적지 입력 UI(D-05): 정류장명 검색(스냅샷) 또는 지도 직접 지정, 검색 결과 없음 처리, 선택 전 탐색 버튼 비활성
2. TASK-012 반경 로직을 출발지·목적지 각각에 적용, 확대 동의를 **위치별로 따로** 요청
3. 후보 0건 위치가 남으면 경로 탐색 미실행, 원인(출발지/목적지 측 정류장 없음) 안내

## 테스트 케이스
- 선택 전·검색 실패 → 탐색 미실행 (AC-006)
- 출발지만 0건 → 출발지에만 확대 동의 요청, 목적지는 500m 유지 (AC-007)
- 둘 다 0건 → 각각 동의 요청, 동의한 위치만 1km
- 동의 후에도 0건 → 경로 미생성, 안내 표시

## 보류 조건
외부 장소 검색은 MVP 범위 밖(D-05). 지도 직접 지정은 PRIV-004 §6.1 확인 전 보류, 정류장명 검색만으로 진행 가능.
