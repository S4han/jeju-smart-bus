승차·하차 후보 정류장과 노선 정차 순서·방향을 근거로 직행 및 1·2회 환승 경로를 규칙 기반으로 찾는다. AI·추측 없이 검증된 연결만 경로로 인정한다.

## PRD 수용 기준 (원문)
- **AC-008:** 같은 노선이라도 출발 정류장이 도착 정류장보다 운행 방향상 앞에 있을 때만 직행으로 인정한다. 역방향·연결 불명 경로는 제외한다.
- **AC-009:** 각 구간의 방향·정차 순서와 환승 정류장 연결이 검증된 경로만 유효하다. 환승 3회 이상 경로는 추천·시간 미확인 목록 모두에서 제외한다.
- **AC-016:** 검증된 경로가 없으면 '검색 가능한 경로 없음' 또는 데이터 확인 불가를 표시하고, 정차 순서·방향·연결 불일치 경로는 제외한다.

## 작업 항목
1. 인덱스: 정류장 → (노선, 방향, 순서) 목록
2. 직행: 같은 `routeId`에서 `stationOrd(승차) < stationOrd(하차)` — 방향은 노선 ID로 구분되고 `updnDir`은 항상 0이라 사용하지 않음(GATE-02-03.md §2)
3. 1회·2회 환승: 구간마다 직행 조건 충족 + 환승 정류장 연결 검증. 환승은 **앞 구간 하차 정류장 ID = 다음 구간 승차 정류장 ID**인 경우만(D-19). 같은 노선으로 다시 갈아타는 조합은 제외
4. 환승 횟수 상한 2를 상수로 강제, 3회 이상 생성 자체를 하지 않음
5. 결과 없음 사유 구분: 경로 없음 / 데이터 확인 불가(불일치·누락)
6. 탐색 성능 측정(R-10)

## 테스트 케이스
- 같은 노선 정방향 → 직행 인정 / 역방향 → 제외 (AC-008)
- 순환 노선(첫=마지막 정류장)에서 마지막 순번을 넘어 처음으로 가는 구간 → 제외 (D-21)
- 같은 정류장이 두 순번에 있는 노선 → 순번 차이가 가장 작은 조합 하나만 (D-21)
- 길 맞은편(다른 ID, 같은 이름) 정류장 간 환승 → 생성하지 않음 (D-19)
- 방향 정보 없는 노선 → 제외 (AC-008)
- 1·2회 환승 각 구간 검증 통과 경로만 포함 (AC-009)
- 3회 환승이 필요한 입력 → 결과 없음 (AC-009)
- 정차 순서 불일치 데이터 → 해당 경로 제외, 사유 "데이터 확인 불가" (AC-016)
- 동일 입력 → 동일 결과 집합(결정적)

## 결과 (2026-10-26)

### 엔진 `src/route/engine.ts` (순수 함수, 브라우저 안에서 실행)
- `indexRoutes`: 정류장 → 노선·위치 색인. 정류장 2개 미만이거나 정류장 목록에 없는 정류장을 가진 노선은 제외하고 그 정류장을 기록(AC-016)
- 한 구간: 같은 노선에서 승차 위치 < 하차 위치, 승차 = 하차 정류장인 구간 없음. 끝 → 처음 넘김 없음. 같은 정류장이 여러 위치에 있으면 순번 차이가 가장 작은 조합(D-21)
- 환승: 앞 구간 하차 정류장 ID = 다음 구간 승차 정류장 ID(D-19), 바로 앞 구간과 같은 노선 불가. `MAX_TRANSFERS = 2` — 3회 이상은 만들지 않음(AC-009)
- 탐색: 승차 후보에서 한 구간으로 닿는 정류장(정방향)·하차 후보에 한 구간으로 닿는 정류장(역방향)을 구해 직행·1회 환승을 잇고, 2회 환승은 가운데 노선을 따라가며 앞쪽에서 가장 나은 첫 구간을 붙인다
- 결과 없음 사유: `no_route` / `data_unavailable`(후보 정류장이 제외된 노선에만 걸릴 때). 현재 스냅샷은 제외 노선 0개라 실제로는 `no_route`만 나옴
- 결과 순서: 환승 횟수 → 걷는 거리(직선, D-03) → 고정 식별자. 식별자는 TASK-017에서 D-07 형식(`노선ID:승차정류장ID>하차정류장ID|…`)으로 변경

### 후보 정리 규칙 — D-29 (A) 승인(2026-10-26), 설정값으로 분리
1. **노선 조합별 대표 1개**(`A>B` 같은 조합에서 승하차 정류장만 다른 경로는 하나만): 걷는 거리 → 탄 정류장 수 → 식별자
2. **환승을 줄일 수 있는 경로 제외**(`PRUNE_REPLACEABLE_TRANSFERS`): 뒤 구간 노선이 하차 전에 승차 후보 정류장을 지나거나, 앞 구간 노선이 승차 뒤에 하차 후보 정류장을 지나면 제외 — 대체 경로(환승 더 적음)는 같은 규칙으로 항상 유효
3. **환승 횟수별 상한 30개**(`MAX_JOURNEYS_PER_TRANSFER_COUNT`)
