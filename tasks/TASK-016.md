## 목적
승차·하차 후보 정류장과 노선 정차 순서·방향을 근거로 직행 및 1·2회 환승 경로를 규칙 기반으로 찾는다. AI·추측 없이 검증된 연결만 경로로 인정한다.

## PRD 수용 기준 (원문)
- **AC-008:** 같은 노선이라도 출발 정류장이 도착 정류장보다 운행 방향상 앞에 있을 때만 직행으로 인정한다. 역방향·연결 불명 경로는 제외한다.
- **AC-009:** 각 구간의 방향·정차 순서와 환승 정류장 연결이 검증된 경로만 유효하다. 환승 3회 이상 경로는 추천·시간 미확인 목록 모두에서 제외한다.
- **AC-016:** 검증된 경로가 없으면 '검색 가능한 경로 없음' 또는 데이터 확인 불가를 표시하고, 정차 순서·방향·연결 불일치 경로는 제외한다.

## 작업 항목
1. 인덱스: 정류장 → (노선, 방향, 순서) 목록
2. 직행: 같은 `routeId`에서 `stationOrd(승차) < stationOrd(하차)` — 방향은 노선 ID로 구분되고 `updnDir`은 항상 0이라 사용하지 않음(GATE-02-03.md §2)
3. 1회·2회 환승: 구간마다 직행 조건 충족 + 환승 정류장 연결 검증. 환승은 **앞 구간 하차 정류장 ID = 다음 구간 승차 정류장 ID**인 경우만(D-19). 같은 노선으로 다시 갈아타는 조합은 제외
4. 환승 횟수 상한 2를 상수로 강제, 3회 이상 생성 자체를 하지 않음
5. 결과 없음 사유 구분: 경로 없음 / 데이터 확인 불가(불일치·누락)
6. 탐색 성능 측정(R-10)

## 테스트 케이스
- 같은 노선 정방향 → 직행 인정 / 역방향 → 제외 (AC-008)
- 순환 노선(첫=마지막 정류장)에서 마지막 순번을 넘어 처음으로 가는 구간 → 제외 (D-21)
- 같은 정류장이 두 순번에 있는 노선 → 순번 차이가 가장 작은 조합 하나만 (D-21)
- 길 맞은편(다른 ID, 같은 이름) 정류장 간 환승 → 생성하지 않음 (D-19)
- 방향 정보 없는 노선 → 제외 (AC-008)
- 1·2회 환승 각 구간 검증 통과 경로만 포함 (AC-009)
- 3회 환승이 필요한 입력 → 결과 없음 (AC-009)
- 정차 순서 불일치 데이터 → 해당 경로 제외, 사유 "데이터 확인 불가" (AC-016)
- 동일 입력 → 동일 결과 집합(결정적)
