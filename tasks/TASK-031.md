## 원인(운영 API 확인, 2026-10-27 00:57 UTC)
- `/api/arrivals?stopId=405000444&routeId=405325401`(254-1)·`405325403`(254-3): 예측 0건 — 지금 이 정류장으로 오는 254번 차량이 운행 중이 아님
- 같은 정류장 전체 도착(BusArrives)에서도 254-1·254-3 행은 차량 없음(`vehicleId` 없음). 다른 노선(예: 253 계열 8분, 282 계열 6분)은 실시간 예측 있음
- 우리 산식(GATE-05)은 실시간 예측만 쓰므로 운행 전 차량의 다음 출발 시각은 알 수 없음(검증된 시간표 없음 — FR-014 GATE-04). 카카오맵의 "1시간 46분 후 예상"은 자체 시간표 기반으로 보임
- 그 밖의 미확인 원인: 긴 노선에서 앞서 가는 같은 노선 차량이 있으면 승차·하차 정류장의 "가장 먼저 오는 차량"이 달라 이동 시간을 낼 수 없음(GATE-05 부분 통과 한계)

## 변경
- 시간 미확인 이유를 경로별로 안내(`timeUnknownReason`, 판정 조건은 `journeyTime`과 동일): 운행 중 차량 없음 / 앞선 다른 차량 / 제때 탈 수 없음 / 조회 안 함·실패
- 총 시간을 못 내도 승차 정류장의 다음 차 실시간 예측이 있으면 "버스 도착 예정 N분 후", 없으면 "지금 오는 버스 없음"
- 시간 미확인 경로 탭 이름: "경로 N"
- 펼친 패널 위로 지도 SDK 표시(NAVER Corp. 등)가 올라오던 문제: 지도 영역을 별도 쌓임 맥락으로(`.map-stage { z-index: 0; isolation: isolate }`)
