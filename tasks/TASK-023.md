## 배치 규칙(`src/ui/layout.ts`의 `mapLayoutFor`, 화면 크기만 사용)
| 화면 | 배치 |
|---|---|
| 세로 휴대폰(폭 768px 미만) | 지도 + 아래 패널(TASK-022 그대로) |
| 태블릿·PC(폭 768px 이상) | 왼쪽 패널(폭 340~440px) + 오른쪽 지도 |
| 가로로 눕힌 휴대폰(가로 > 세로, 폭 560px 이상) | 왼쪽 패널 + 오른쪽 지도(높이가 낮아 아래 패널이 비좁음) |
| 지도 미동의(모든 기기) | 카드 화면, 폭 768px 이상에서는 최대 폭 600px |

- 창 크기·방향이 바뀌면 배치도 바로 바뀜
- 왼쪽 패널 배치: 출발·도착 요약은 패널 안(지도 위 카드 없음), "경로 찾기"는 패널 아래에 고정, 지도 범위 맞춤 여백 48px
- **NAVER 로고 보호:** 왼쪽 패널과 지도 영역은 겹치지 않음(지도는 패널 오른쪽에서 시작)
- 높이 500px 이하 화면: 제목·하단 버튼 높이를 줄임
- 마우스가 있는 기기: 누를 수 있는 행에 마우스를 올리면 배경 표시

- 미확인: 실제 NAVER 지도가 창 크기 변경(PC 창 조절, 기기 회전) 때 지도 크기를 따라 다시 그리는지 — 작업 환경에서 SDK를 불러올 수 없어 미리보기·실기기 확인 필요
