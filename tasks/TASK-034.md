# TASK-034 — 지도에서 고르기: 누른 지점에 핀 + 반경 1km 정류장 미리보기

| 항목 | 내용 |
|---|---|
| Phase | 5 — 사용성 개선 |
| 상태 | 구현(브랜치, 2026-10-27) — 사용자 확인 대기 |
| 관련 | FR-002·FR-006(지도 직접 지정, D-05), FR-004, AC-003·AC-007(확정 후 후보 규칙 그대로) |
| 요청 | 사용자(2026-10-27): "지도를 누르면 핀 위치가 누른 지점으로 맞추고 반경 1키로 주변 정류장 표시되게 가능??" |

## 변경
- "지도를 눌러 ○○ 고르기"를 켜면 지도 위쪽에 안내("지도를 눌러 ○○를 고르세요 [취소]"). 휴대폰에서는 고르는 동안 출발·도착 요약 카드 자리에 표시(지도와 패널 사이 공간이 좁아 카드 아래에 두면 패널에 가려짐)
- 지도를 누르면 바로 확정하지 않고 그 지점에 📍 핀 + 반경 **1km** 정류장 표시(500m 밖은 흐리게), 지도는 핀·정류장이 보이게 맞춤. 다시 누르면 핀 이동
- 안내에 "반경 1km 정류장 N곳(500m 안 M곳, 가장 가까운 곳 Xm)" + [이 위치로 정하기] [취소]. 미리 보인 정류장 마커를 누르면 그 정류장으로 바로 지정
- 1km 안에 정류장이 없으면 "이 지점으로는 버스 경로를 찾을 수 없어요" — [이 위치로 정하기] 비활성
- 1km는 고르기를 돕는 **미리보기**이다. 확정 후 경로 후보는 기존 규칙(500m, 0건이면 동의 후 1km — AC-003·AC-007)과 짝 정류장(D-32) 그대로
- NAVER 로고는 지도 아래쪽 — 안내는 위쪽이라 가리지 않음

## 검증
- `npm test` 236개(미리보기 마커 테스트 추가)·`npm run build` 통과
- 휴대폰 크기 브라우저(가짜 지도 SDK로 지도 클릭 발생): 고르기 시작 → 누름 → 안내 "반경 1km 정류장 10곳(500m 안 1곳, 가장 가까운 곳 493m)" → [이 위치로 정하기] → 도착 "지도에서 고른 지점" 확인
- 미확인: 실제 NAVER 지도에서 핀·흐린 정류장 모양 — 실기기 확인 필요
