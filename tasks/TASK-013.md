# TASK-013 — 정류장 지도·목록 동기화 (FR-004, FR-020 정류장 부분)

|---|---|

| 상태 | 미착수 |

## 목적
같은 정류장 검색 결과를 지도와 목록에 동시에 표시하고, 선택한 정류장을 양쪽에서 식별할 수 있게 한다.

## PRD 수용 기준 (원문)
- **AC-004:** 목록과 지도는 동일한 유효 정류장 집합을 사용하고 선택한 정류장을 식별할 수 있다. 좌표가 없는 정류장을 임의 위치에 표시하지 않는다.
- **AC-020 (정류장 부분):** 유효 좌표가 있는 정류장과 경로 지점을 표시한다. 실제 도로·버스 운행 궤적 데이터가 없으면 추정 선을 실제 운행 경로처럼 표현하지 않는다.

## 작업 항목
1. 단일 결과 상태를 지도·목록이 공유(별도 필터링 금지)
2. 목록 선택 ↔ 지도 마커 강조 양방향 동기화, 접근성(목록 항목 키보드 선택, 선택 상태 텍스트 표시)
3. 모바일 레이아웃: 지도 + 목록 전환 또는 분할(디자인은 구현 시 사용자 확인)
4. 출발지 표시 마커(정류장과 구분)
5. 좌표 확인 불가 정류장(D-24)은 지도 마커 없이 목록·경로 단계에만 "좌표 확인 불가"로 표시

## 테스트 케이스
- 지도 마커 ID 집합 = 목록 ID 집합
- 목록 선택 → 해당 마커 선택 상태, 마커 선택 → 목록 항목 선택 상태
- 좌표 누락 정류장은 지도·목록 어디에도 유효 결과로 나오지 않음(반경 계산 불가)
- PoC 회귀 체크리스트 통과
