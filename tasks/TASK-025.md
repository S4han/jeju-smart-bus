# TASK-025 — 목록에서 고른 정류장으로 지도 이동

|---|---|
| Phase | 5 — 사용성 개선 |

| 관련 | FR-004·AC-004(지도·목록 동기화), US-002 |
| 요청 | 사용자(2026-10-27, 휴대폰 실사용): 목록에서 고른 정류장("정든마을")이 지도 화면 밖에 있어 보이지 않음 → "고쳐줘" |

## 변경
- 주변 정류장 목록(또는 지도 마커)에서 정류장을 고르면, 그 정류장이 지도 화면 밖이거나 위에 떠 있는 출발·도착 카드에 가려질 때만 지도를 옮김(`NaverMap`의 `focus`, SDK `panToBounds` — 확대 수준 유지)
- 이미 보이는 정류장은 지도를 움직이지 않음
- 여백은 배치별 지도 맞춤 여백과 같음(휴대폰: 위 150px, 태블릿·PC: 48px)

## 범위 밖(결정 대기)
- 같은 이름의 길 건너 정류장이 500m를 조금 넘어 지도·목록에서 빠지는 문제(예: 정존마을 405000443)는 PRD AC-003(500m 이내만 기본 결과)과 관련되어 사용자 결정 전 변경하지 않음

## 검증
- `npm test`·`npm run build` 통과(타입 정의에서 `panToBounds(bounds, transitionOptions, margin)` 확인)
- 미확인: 실제 NAVER 지도에서 이동 동작 — 작업 환경에서 SDK를 불러올 수 없어 실기기 확인 필요
