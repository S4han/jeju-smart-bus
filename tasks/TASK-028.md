## 변경(사용자 승인 불필요 항목만)
1. **경로 찾기 → 결과로 이동:** 결과가 나오면 패널을 펴고 결과 위치로 스크롤. 하단 고정 "경로 찾기" 버튼은 결과가 있으면 치우고 결과 아래 "다시 찾기"로 바꿈
2. **출발지·목적지 접기:** 정한 뒤에는 "현재 위치"/"정류장: ○○"와 "변경" 버튼만 표시. "변경"(또는 위 요약 카드)을 누르면 선택 화면이 열리고, 고르면 다시 접힘. 변경 중 "변경 취소", 출발지는 "현재 위치로" 복귀 버튼
3. **주변 정류장 목록:** 가까운 5곳만 먼저, 나머지는 "N곳 더 보기". 지도에는 전체 표시(AC-004 같은 집합). 지도에서 접힌 정류장을 고르면 목록이 펼쳐짐
4. **같은 이름 정류장 구분:** 검색 결과에 같은 이름이 여러 곳이면 "다음 정류장: ○○"(스냅샷 노선 정차 순서) 표시. 결과에 기준 위치에서의 거리 표시(출발지 검색: 현재 위치, 목적지 검색: 출발지 — 브라우저 안에서만 계산)
5. **검색 보완:** 부분 일치가 없고 3글자 이상이면 글자 순서 포함으로 찾음("제주공항" → "제주국제공항…"). 이름을 만들거나 바꾸지 않음
6. **결과·상세 정리:** 상세는 단계 안내(어디서 타고 내리는지)를 먼저, 추천 근거는 첫 줄을 보여 주고 나머지는 "추천 근거 자세히"(AC-018 표시 유지). 추천 경로가 있으면 "소요시간 미확인 경로 N개 더 보기"·"경로 비교표 보기"로 접음(내용·순서는 그대로)
7. **출발·도착 바꾸기 버튼(⇅)**, 패널을 펴면 요약 카드를 패널 안에 표시
8. **누르기 쉬운 크기:** 패널 손잡이·링크 버튼 높이 44px 이상
