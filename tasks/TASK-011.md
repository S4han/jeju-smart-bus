## PRD 수용 기준 (원문)
- **AC-001:** 권한 허용·좌표 확보 시 현재 위치가 출발지로 설정된다. 권한 거부·좌표 실패 시 강제 진행하지 않고 수동 입력을 제공한다.
- **AC-002:** 위치 권한이 없어도 선택한 출발지로 정류장·경로 검색을 시작할 수 있다. 선택할 수 없는 입력은 유효한 출발지로 처리하지 않는다.

## 작업 항목
1. 권한 요청 전 사용 목적 안내(TASK-002 문구), Geolocation 호출, 상태(요청 중/허용/거부/실패/시간 초과) 처리
2. 좌표는 메모리 상태로만 보관 — URL·localStorage·서버 전송 금지(D-01 A안 기준)
3. 거부·실패 시 수동 입력 UI로 전환, 재시도 수단 제공(강제 진행 없음)
4. 수동 입력(D-05): ① 정류장명 검색 — 스냅샷 정류장 이름 부분 일치, **목록에서 선택한 정류장만** 출발지(좌표 확인 불가 정류장은 선택 불가 또는 안내) ② 지도 직접 지정 — 지도를 눌러 고른 지점을 출발지로(좌표만, 장소명 없음 — 역지오코딩 API 미사용). 자유 텍스트만 입력된 상태는 무효

## 테스트 케이스
- 권한 허용 + 좌표 → 출발지 = 현재 위치 (AC-001)
- 권한 거부 / 좌표 오류 / 시간 초과 → 수동 입력 표시, 검색 미시작 (AC-001)
- 권한 없음 + 수동 선택 완료 → 검색 시작 가능 (AC-002)
- 선택하지 않은 텍스트 입력 → 출발지 미설정 (AC-002)
- 좌표가 URL·storage·네트워크 요청에 포함되지 않음 (PRIV)

## 보류 조건
PRIV 미통과 시 착수 금지. D-05 미결정 시 FR-002는 보류(FR-001만 진행 가능, 단 거부 시 "수동 입력 준비 중" 같은 미검증 기능 노출 금지 여부는 사용자 확인).
