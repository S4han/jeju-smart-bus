## 3. PRIV-001 — 서버 DB 영구 저장 금지

설계 근거:
- 서버 측 저장소 미도입: DB·KV·Blob·Edge Config 등 사용하지 않음(AGENTS.md 규칙 4·5, GATE-06 Marketplace 과금 위험과도 일치).
- 서버 함수 입력은 정류장 ID 등 비위치 파라미터로 한정. `lat`, `lng`, `x`, `y`, `latitude`, `longitude`, `coords` 등 좌표성 필드가 오면 **400으로 거부**하고 값은 로그에 남기지 않음(TASK-004 단위 테스트).
- 경로 탐색은 브라우저에서 수행(D-01) → 서버가 좌표를 받을 이유가 없음.

예외 경로: 도보 API 키를 서버에 둬야 해서 좌표가 서버를 경유하게 되면(R-18) 이 판정은 **재검증 대상**이다. 그 경우에도 저장 없이 요청 처리 후 폐기, §4 로그 규칙 적용.

## 4. PRIV-002 — 로그 최소화

| 로그 종류 | 위험 | 규칙(구현 체크리스트) |
|---|---|---|
| Vercel 접근·런타임 로그 | 요청 경로·쿼리스트링이 기록됨(`requestPath` 단위 조회 가능) | 좌표를 URL 경로·쿼리에 절대 넣지 않음. 서버로 보낼 경우 요청 본문 사용 |
| 서버 함수 `console.*` | 런타임 로그에 남음 | 요청 본문·헤더·외부 응답 원문 출력 금지. 오류는 정규화된 코드(`unavailable` 등)와 요청 ID만 |
| 외부 API 오류 메시지 | 키·URL 포함 가능 | 키 마스킹 후 코드만 기록 |
| 브라우저 콘솔 | 사용자 기기에만 남지만 디버깅 습관으로 좌표 출력 위험 | 좌표 `console.*` 출력 금지(리뷰 체크). 개발용 로그도 커밋 금지 |
| 오류 수집 도구(Sentry 등) | 상태·URL·breadcrumb에 좌표 포함 | MVP 미도입(D-13 취지). 도입 시 PRIV 재검증 |
| 분석 도구 | 페이지 URL·이벤트 | Vercel Web Analytics·Speed Insights·로그 드레인 미사용(D-13 승인) |
| 빌드 로그 | 해당 없음 | — |
| 저장소·테스트 픽스처 | 실제 사용자 좌표 커밋 | 픽스처 좌표는 정류장 공개 좌표 또는 합성 좌표만 |

조건부 사유:
1. **D-22(신규):** 도착정보 요청 `GET /api/arrivals?stopId=…`는 정류장 ID가 접근 로그에 IP와 함께 남는다. 정류장 ID는 좌표가 아니고 공개 시설 식별자이지만, 사용자 관심 위치를 간접적으로 드러낼 수 있다.
   - (A) GET + URL의 정류장 ID 허용 → CDN 캐시로 호출량 절감(NFR-002에 유리). 로그 보존은 Vercel 기본값에 한정, 드레인 없음.
   - (B) POST + 본문 → URL 로그에 남지 않으나 CDN 캐시 불가 → 버스 API 호출량 증가.
   - 제안: (A). 정류장 ID는 PRD가 정의한 "위치정보(현재·선택 위치)"가 아니며, 쿼터 보호 효과가 큼. **사용자 승인 필요.**
2. Vercel Hobby 로그 보존 기간은 원문 미확인(GATE-06 §1 접근 차단). 사용자 대시보드 확인 또는 재조사 필요.

## 6. PRIV-004 — 외부 서비스로 전달되는 좌표

### 6.1 NAVER Dynamic Map — 조건부

- 전달: 지도 중심을 사용자 위치로 이동하면 타일·SDK 요청이 그 주변 영역을 드러냄. 사용자 위치 마커는 브라우저에서 그려지며 정확한 좌표가 별도로 전송되는지는 **미확인**(SDK 내부 동작 — TASK-010에서 네트워크 요청 관찰로 확인).
- 제공업체 저장·재이용 조건: NAVER Cloud 이용약관·개인정보처리방침 원문 미열람(네트워크 차단).
- 판정: 기존 PoC(제주시 고정 중심)는 사용자 위치를 쓰지 않으므로 영향 없음. **사용자 위치로 지도 중심을 옮기는 기능(TASK-011·013)은 아래 확인 전 보류.**
  - [ ] NAVER Cloud Maps 약관·처리방침의 요청 데이터 처리 조항 확인(사용자 또는 차단 해제 후 재조사)
  - [ ] TASK-010에서 SDK 네트워크 요청에 정확한 좌표가 포함되는지 관찰

### 6.2 장소 검색(U-001) — 보류

- 공급자 미정(TASK-008). 원칙: **검색어만 전송, 위치 편향 좌표 미전송**을 기본으로 한다. 좌표 전송이 필요하면 해당 공급자 약관 확인 후 사용자 승인.
- Kakao(후보): 운영정책상 캐시는 사용자 환경 개선 목적만, 데이터 복사·제공 금지. 전달 좌표의 저장·재이용 조항은 미확인.

### 6.3 도보 데이터(U-002) — 보류

- 도보 경로 API를 쓰면 출발·도착 좌표가 반드시 외부로 전달된다. REST 키를 서버에 두면 자체 서버도 경유(R-18).
- D-06에서 "도보 API 사용"이 선택될 경우에만 해당 공급자 조건을 검증한다. "직선거리 기반 추정" 또는 "미제공"을 선택하면 외부 전달이 없다.
