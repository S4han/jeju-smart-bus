## 3. 명세 대비 정리

- `localX` = 경도, `localY` = 위도 (명세와 일치, 1건 예외)
- 정류장 ID 형식: 9자리 숫자(관찰 범위). `server/request-guard.ts`의 보수적 패턴은 유지하되 TASK-009에서 9자리 숫자로 좁히는 것을 제안
- 증분 조회 `last` 파라미터는 이번에 시험하지 않음

## 4. 통과 조건 (데이터 가공 규칙 — TASK-009 반영)

1. `useYn=Y` 정류장만 검색 대상으로 사용
2. 문자열 `"null"`은 값 없음으로 처리
3. **뒤바뀐 좌표는 자동으로 바로잡지 않는다**(검증되지 않은 정보 생성 금지, NFR-004) — 해당 정류장은 "좌표 확인 불가"로 지도·반경 검색에서 제외하고 목록에 남길지 사용자 결정(**D-24 신규**)
4. 범위 밖 61건은 TASK-006에서 위치(추자도 등)를 확인해 정상/오류를 분류
5. 정적 스냅샷은 전체 1회 조회로 생성 가능(약 1.1MB XML) — D-01 유지 근거
