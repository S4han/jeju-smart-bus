# 경로선(도로 경로) 길찾기 API 조사 — 2026-10-27

사용자 요청: 카카오맵처럼 정류장을 잇는 도로 경로선을 그릴 수 있는지(선택지 D: 길찾기 API). 조사만 수행, 코드 변경 없음.

## 1. 카카오모빌리티 길찾기 API (공식 페이지 확인)
| 항목 | 내용 | 출처 |

| 인증 | 카카오디벨로퍼스 REST API 키(`Authorization: KakaoAK …`) → 서버 전용 키 필요(규칙 7) | 위 페이지 |

| 초과 요금 | 무료 초과분만: 자동차 8원/건, 다중 경유지 16원/건 | 위 페이지 |
| 상업적 이용 | 가격 페이지에는 제휴 문의 메일만. 개발자 포럼 답변: 상업적 목적이면 무료 쿼터 내라도 사전 제휴 계약 필요(공식 약관 원문 미확인) | devtalk.kakao.com |

호출 수 예: 254번 정존마을→일과2리(정류장 52곳) = 출발·도착 + 경유지 30개씩 → 2회. 경로 상세를 열 때마다 호출(캐싱 금지 가정) → 하루 약 2,500회 상세 보기까지 무료 범위(다른 사용 없을 때).

## 2. NAVER Cloud Maps Directions 5/15 (공식 페이지 접속 불가 — 작업 환경 DNS 차단)
- 검색 결과 요약(원문 미확인): Directions 5 경유지 5개, Directions 15 경유지 15개(참조서에는 5개로 적힌 곳도 있어 불일치). 2025 공지: Maps API 월 무료 이용량 제공이 2025-07-01 종료, Directions 15 건당 20원
- 판단: 무료 제공 종료가 사실이면 첫 호출부터 과금 → 월 0원 원칙(규칙 4)과 충돌. 콘솔·공지 원문 확인 필요(사용자)

## 3. 공통 위험
- 자동차 경로이므로 버스 실제 운행 경로와 다를 수 있음(전용차로·회차·버스만 다니는 길)
- 카카오 경로 결과를 NAVER 지도 위에 그려도 되는지(타사 지도 표시) 약관 미확인
- 서버 키·서버 함수 추가(`api/` 함수, 환경변수) 필요 — 규칙 7·AGENTS §4에 따라 사용자 승인 대상
- 위치정보: 요청에는 정류장 좌표만(사용자 좌표 아님) — 단, 걷기 구간까지 그리면 사용자 좌표가 전송되므로 제외해야 함(PRIV)

## 4. 결론(제안)
- NAVER Directions: 월 0원 유지 어려움(무료 제공 종료 정보) → 제외 권장
- 카카오 다중 경유지: 무료 한도(일 5,000건)로는 가능성 있으나, 도입 전 카카오모빌리티에 서면 확인 필요 — ① 이 서비스의 상업적 이용 해당 여부·제휴 필요 여부 ② 결과 캐싱(노선별 저장) 허용 여부 ③ NAVER 지도 위 표시 허용 여부 ④ 무료 초과 시 과금인지 차단인지(과금 차단 설정 가능 여부)
