## 3-A. NAVER 검색 API — 지역 검색 상세

출처(원문, 2026-10-26 열람): [지역 검색 API](https://developers.naver.com/docs/serviceapi/search/local/local.md), [검색 API 소개](https://developers.naver.com/products/service-api/search/search.md), [오류 코드](https://developers.naver.com/docs/common/openapiguide/errorcode.md), [NAVER API 서비스 이용약관(2026-10-07 개정)](https://developers.naver.com/products/terms/)

| 항목 | 내용 |
|---|---|
| 엔드포인트 | `GET https://openapi.naver.com/v1/search/local.json` (개발자센터 기준) |
| 인증 | 헤더 `X-Naver-Client-Id`, `X-Naver-Client-Secret` |
| 파라미터 | `query`(필수), `display`(1~5), `start`(1), `sort`(random=정확도 / comment=리뷰 수) — **좌표·지역 파라미터 없음** |
| 응답 | `title`, `link`, `category`, `description`, `address`, `roadAddress`, `mapx`, `mapy` ("WGS84 좌표계 기준", integer) |
| 좌표 주의 | 문서는 WGS84라고 하나 integer이며, 응답 예시 값(`311277`, `552097`)이 경위도 형태가 아님 → **변환 규칙을 실호출로 확인해야 함**(AGENTS.md 규칙 8) |
| 한도 | 하루 25,000회. 초과 시 429(호출 한도 초과), 초당 초과도 429 |
| 신규 신청 | 약관 부칙 제2조: 2026-07-30 24:00 개발자센터 신규 신청 중단, NCP **NAVER API HUB**로 이관. 기존 이용자는 2027-06-30까지 유지 |
| API HUB 요금 | [원문](https://www.ncloud.com/product/applicationService/naverApiHub): "검색 API 무료 0 ~ 775,000건 0원 일 최대 25,000건 호출 제한", "서비스 이용량은 API 호출 횟수를 기준으로 집계됩니다. 한시적 무료 제공 정책은 추후 변경될 수 있습니다." 상품 소개: "종량제 방식", "호출량 모니터링과 임계치 설정" |

PRIV-004 관점:
- 사용자 좌표는 보내지 않지만 **검색어가 NAVER에 최대 1년 보관·활용**된다(약관 11.5). 약관 11.6에 따라 **이용자 동의를 받아야** 한다 → 위치 권한 안내와 별도로 검색 기능 사용 전 고지·동의가 필요.
- 서버 함수가 Secret을 들고 중계하므로 검색어가 자체 서버를 거친다 → D-23(POST 본문, 로그 미기록) 적용.

## 3. Kakao 키워드 검색 상세

출처: [로컬 API 개발 가이드](https://developers.kakao.com/docs/latest/ko/local/dev-guide), [카카오맵 공통](https://developers.kakao.com/docs/latest/ko/kakaomap/common), [쿼터](https://developers.kakao.com/docs/latest/ko/getting-started/quota), [운영정책](https://developers.kakao.com/terms/latest/ko/site-policies) — 2026-10-26 열람

| 항목 | 내용 | 근거 |
|---|---|---|
| 엔드포인트 | `GET https://dapi.kakao.com/v2/local/search/keyword.${FORMAT}` | 원문 |
| 인증 | `Authorization: KakaoAK ${REST_API_KEY}` | 원문 |
| 필수 파라미터 | `query` | 페이지 요약 |
| 선택 파라미터 | `x`, `y`(중심 경도·위도), `radius`(최대 20,000m), `rect`(좌X,좌Y,우X,우Y), `category_group_code`, `page`(1~45), `size`(1~15), `sort`(accuracy/distance — distance는 x·y 필요) | 페이지 요약 — 실호출로 확인 |
| 응답 | `place_name`, `address_name`, `road_address_name`, `x`(경도), `y`(위도), `id`, `category_name`, `place_url` 등 | 페이지 요약 |
| 좌표계 | 경위도로 설명됨. 키워드 검색 절에서 WGS84 명시는 확인 못함 | 실호출로 확인 |
| 무료 쿼터 | 키워드 검색 일 100,000건, 월 전체 3,000,000건 | 원문(GATE-06 §3.4) |

## 4. 위치정보 관점 (PRIV-004 연계)

- ①을 쓰더라도 **사용자 현재 위치는 보내지 않는 구성**이 가능하다: 검색어 + 제주 고정 `rect`. `sort=distance`(사용자 기준 거리순)는 좌표가 필요하므로 쓰지 않는다.
- 다만 **검색어 자체가 목적지를 드러낼 수 있다**(예: 숙소 이름). 좌표는 아니지만 민감할 수 있으므로 자체 서버 로그에 남기지 않도록 전송 방식을 정해야 한다 → **D-23(신규)**.
- 검색 결과 좌표는 공개 장소의 좌표이지만, 사용자가 고른 결과는 "선택 위치"가 된다 → 응답은 `Cache-Control: no-store`, 브라우저 메모리에만 보관(PRIV-003 규칙과 동일).

## 5. 제안 (사용자 선정 필요)

> 아래는 제안이다. 선정 전에는 어떤 공급자도 연동하지 않는다(AGENTS.md 규칙 9).

| 구분 | 제안 | 이유 |
|---|---|---|
| MVP 기본 수단 | **③ 정류장명 검색 + ② 지도 직접 지정** | 0원 보장, 새 공급자·키·동의 절차 없음, 사용자 좌표 외부 전달 없음(지도 타일 제외) |
| 일반 장소 검색(후속 또는 MVP 추가) | **④ NAVER 지역 검색을 1순위 후보**로 두되 아래 조건 확인 후 결정 | 지도와 같은 공급자로 통일, 사용자 좌표 미전송 |
| ④ 채택 전 확인 | ① API HUB: 일 25,000건 초과 시 차단(429)되는지 과금되는지, 결제수단 등록 필요 여부(NFR-001) — 콘솔 확인 ② 약관 2.1 용도 적합성(검색 결과를 경로 탐색 목적지로 쓰는 것) ③ 결과 5개·지역 파라미터 없음으로 제주 검색 품질이 충분한지(실호출) ④ `mapx`·`mapy` 좌표 변환 ⑤ 검색어 1년 보관에 대한 이용자 동의 문구 | 약관·비용 위반 방지 |
| ① Kakao | 예비 후보 | ④가 조건을 통과하지 못할 때만 재검토 |

핵심 선택: ②+③만으로는 관광객이 명소 이름으로 목적지를 찾기 어렵다. 이 한계를 MVP에서 받아들일지, ④ 확인을 MVP 전에 끝낼지 정해야 한다.
